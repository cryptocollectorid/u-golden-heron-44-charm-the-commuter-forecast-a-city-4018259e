## Entry

> In Brollywood, rain falls upward this morning, so umbrellas are decorative and the 8:15 bus is somehow on time for once.

## Run

```sh
python3 main.py
```

Writes the forecast to `/output/entry.txt` and prints it. Gate: 1–140 UTF-8 characters.
